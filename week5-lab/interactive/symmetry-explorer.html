The invariant model's line is flat to machine precision, roughly 1e-16. That is not a very small error; it is the same number computed twice. The Python lab measures the identical thing on a trained model and gets 8.88e-16 against 1.76e-01 for the coordinate model.

How much of the input space the symmetry removes

Rotations and translations are directions in the input that carry no information.

When the symmetry is false

The honest half. A symmetry is a promise about the world. Add a gravity term and the energy really does depend on which way up the arrangement sits, so an invariant model has thrown away the very information it needs, and no dataset can give it back. The Python lab measures this too: with a gravity term the invariant model scores 0.236 against the coordinate model's 0.093. A false constraint is not a handicap, it is a wall.
